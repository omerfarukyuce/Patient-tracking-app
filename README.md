# 🏥 Hospital Patient Management System

This project is a simple hospital patient management system that allows you to add, delete, update, search, and print patient records. It is written in C and stores patient data in a binary file.

## 🚀 Features

- ➕ Add Patient
- ❌ Delete Patient
- ✏️ Update Patient
- 🔍 Search Patient
- 📝 Print All Patients
- 🔄 Initialize Patient Records (Reset)

## 📦 Requirements

- C Compiler (e.g., GCC)
- Windows Operating System (for file handling)

## 🔍 Usage

1. Clone or download the project.
2. Compile the `main.c` file using a C compiler.
3. Run the program.
4. Select the desired operation from the menu.

## 🧩 Example Usage

When the program runs, you will see a menu like this:

Hospital Patient Management System
1. Add Patient
2. Delete Patient
3. Update Patient
4. Search Patient
5. Print All Patients
6. Initialize Patient Records (Reset)
0. Exit
Enter your choice:


Follow the options to manage patient information.

## 📁 File Structure

- `main.c`: The main code of the application.
- `patientRecords.dat`: The binary file used to store patient records.
